DESCRIPTION:

	The goal of this design is to show how to use Active-HDL
	for VHDL designs intended for MATLAB Simulink.	


Design is simple example of amplitude modulation/demodulation channel.


The workspace contains the following designs:
	
	Modulator	- VHDL equivalent model designed to replace "Modulator" block 
					in Simulink diagram
	Demodulator - VHDL equivalent model designed to replace set of blocks
					used to build demodulator in Simulink diagram:
					"Abs", "Sign" and "FIR_filter"
				  This design includes block diagram connecting submodules to 
					create demodulator module.
														  
The workspace folder includes also:
	
	Modulation_cosim.mdl - Simulink diagram of modulation/demodulation channel 
							with ALDEC blocks described in VHDL


Modulation.mdl is simple example of amplitude modulation/demodulation channel.
Two sinusoidal signals, carrier and information, are multiplied. On the output 
of multiplier the amplitude modulated signal can be observed.
This signal is applied to demodulator built with use of:
- rectifier which is simple abs funtion extracting absolute value 
	of modulated signal ("Abs" block)
- information signal LowPass FIR filter used to attenuate carrier frequency from 
	modulated signal and thus extract its envelope which holds information 
	("carrier_FIR" block)
- sign detector used to extract frequency of the carrier ("Sign" block)
- carrier LowPass FIR filter used to filter out high harmonic components from 
	square wave present on sign detector's output ("envelope_FIR" block)

Once algorithm is tested in simulink environment, designer can use VHDL equivalent
descriptions of modulator and demodulator which will be used in FPGA implementation
process. This way test enviroment build in Simulink will stimulate VHDL components 
and examine their response.



CO-SIMULATION:

To start cosimulation of this design, we need to create ALDEC Blockset compatible 
with Simulink Library browser, which will include Simulink(R) compatible models 
of our HDL components.

Please refer to On-Line Documentation, use keyword Simulink to find detailed 
description of Simulink(R) Interface, including step by step instructions on 
how to use CoSimulation Wizard for Simulink.

Simulink blocks should be created for following modules:
1. top_demodulator (compiled to demodulator design library).
2. mult (compiled to modulator design library).

Run the Co-Simulation Wizard for Simulink in Active-HDL and specify the following 
settings (leave default if not specified below):

For "mult" block set:

Port Sin_wav1: Cast = unsign, Number of Bits = 16, Fractional Part = 9
Port Sin_wav2: Cast = sign, Number of Bits = 16, Fractional Part = 15
Port Out1: Cast = sign, Number of Bits = 31, Fractional Part = 24

For "top_demodulator" block set:

Clock signal: 	clk
CE signal: 		ce

Port reset : Cast = bool, Number of Bits = 1, Fractional Part = 0
Port In1 : Cast = sign, Number of Bits = 31, Fractional Part = 24   
Port carrier : Cast = unsign, Number of Bits = 21, Fractional Part = 0  
Port envelope :	Cast = sign, Number of Bits = 21, Fractional Part = 0   

This module contains internal signals which cannot be observed in Simulink(R)
environment. Selecting "Add to waveform" option allows to observe them 
in Active-HDL waveform viewer. This switch enables additional dialog 
displaying design's hierarchy. By default only interface signals are selected,
in this design it is recommended to select also two internal signals abs_out and
sign_out.

Next, start MATLAB and choose the Set Path option form the File menu. 
This option allows you to specify the path to the directory that you have 
specified in the Output Directory field of the Co-Simulation Wizard for Simulink 
window (by default, C:\My_Designs\Samples_61\MATLAB_EXAMPLE\Matlab\). 
Click the Add Folder button and browse for Output Directory. Then, click OK. 
Choose the Save option and close the Set Path window by pressing the Close button.
Open Simulink Library browser. It should contain ALDEC Blockset with modules 
generated by Simulink Co-Simulation Wizard in Active-HDL.

Then, open Modulation_ahdl.mdl model in the Simulink environment. It uses
black-boxes coming from the ALDEC Blockset library, corresponding to modulator and
demodulator parts of original mathematical model (modulation.mdl).
Notice that Active-HDL CoSim block must be added in order to run cosimulation.
Double-click on this block and set Simulink System Period = 1/20. 
All other blocks are designed to work with the same clock frequency, so set 
Black-Box Sample Period = 1/20 also for all other blocks.

Run the co-simulation employing HDL black-boxes and verify simulation results 
in Active-HDL's Waveform Viewer or Simulink's Scope.

For more information on the Co-Simulation Wizard for Simulink, refer to 
the Active-HDL on-line documentation.
